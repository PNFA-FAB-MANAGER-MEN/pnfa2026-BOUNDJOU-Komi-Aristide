# Appris

- L’ILI9341 fonctionne en 3.3V et SPI. Il s’allume même sans code, juste avec VCC/GND.
- L’ESP32-C3 DevKit V4 utilise souvent des drivers CH343 ou CP210x différents des ESP32 classiques
- Sur Wokwi, on peut créer ses propres composants comme les condensateurs.
- Pour flasher un ESP32 il faut : Bon driver + Bon port COM + Bouton BOOT maintenu.

# Raté, puis corrigé

- Impossible de télécharger/uploader le code sur l’ESP32-C3 DevKit V4
- Driver USB-Série non installé,Téléchargement des drivers SP02x.
- Simulation Wokwi échouée, Librairie ILI9341 non compatible.

## Décidé
